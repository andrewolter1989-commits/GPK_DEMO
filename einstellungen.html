Lokal starten

  1. Node.js installieren.
  2. Im Projektordner npm install ausführen.
  3. Danach npm start.
  4. http://localhost:3000 öffnen.
Demo-Login: admin@gpk.local · Passwort demo1234. Für produktiven Einsatz werden Secret, HTTPS, PostgreSQL und sichere Benutzerverwaltung eingerichtet.
